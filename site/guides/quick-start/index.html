Quick start: your first sentence in 5 minutes

No sign-up, no download, nothing to buy. Here's the fastest path from opening SayThrough to hearing it speak.

1. Open the app

Go to the app and tap “Try it first — nothing is saved” to jump straight in, or “Let's set up a voice” to create a saved profile (recommended if this is for someone who'll use it regularly).

2. Build a message

You'll see a grid of color-coded words and picture symbols. Tap any word — like I, then want, then more — and each one is added to the message bar at the top.

  • Made a mistake? Tap the ⌫ to remove the last word.
  • Want a different form of a word? Press and hold it (e.g. go → going).
  • Need a word without a button? Open the Keys tab to type it.

3. Speak it

Press the green ▶ Speak button and SayThrough reads the whole sentence aloud, highlighting each word as it's spoken. Tapping the sentence itself also speaks it.

Tip: In Settings you can turn on “speak each word as you tap,” pick a voice, and adjust the speaking speed.

4. Install it on your device

SayThrough is a web app you can install so it opens full-screen and works offline:

  • iPad / iPhone (Safari): tap the Share icon → Add to Home Screen.
  • Chromebook / Chrome / Edge: click the Install icon in the address bar (or menu → Install SayThrough).
  • Android: menu → Add to Home screen.

Next steps

  • Create a profile and pick a starting vocabulary.
  • Customize the board — edit buttons, add your own photos, and link pages.
  • Set an access method (touch, dwell/hover, or switch scanning) in Settings.
